# solvix-restaurant-qr — restaurant QR ordering system, step by step

Format and topic from the reference in the user's Drive folder (dark step-by-step product walkthrough);
script rewritten in our own words, shorter, Indian payments (UPI), Solvix logo colours (black + neon green).
All screens are designed mock-ups for a demo restaurant "Swaad Kitchen" (not a real client, not a real app).
Steps: 01 scan QR -> 02 menu (rate, spice level, allergy info) -> 03 order -> kitchen screen -> 04 kitchen display
with live orders and timers -> 05 customer's cooking timer -> 06 call waiter + live floor map -> 07 split bill and
pay at the table (cash, card, UPI) -> 08 one-tap review -> overview (table, kitchen, staff) -> comment SOFTWARE.
NOTE for Solvix: the reel promises these features. Offer them only if Solvix can build/deliver this system.
